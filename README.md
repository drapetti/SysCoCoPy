SysCoCoPy implements comparisons of systematic error correctors of time series data using lightkurve (https://github.com/lightkurve/lightkurve).

InSimPy, in an initial development phase, generates stellar variation injection simulations, using TESS_PRF (https://github.com/keatonb/TESS_PRF), that can then be analyze with SysCoCoPy.
